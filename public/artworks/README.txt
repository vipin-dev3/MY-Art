Drop your drawing image files (.jpg, .jpeg, .png, .webp) directly into this folder:
c:\Users\avata\ART\public\artworks\

Example:
If you place a file named "my-drawing.jpg" here, you can reference it in src/data/artworksData.js like this:

  image: '/artworks/my-drawing.jpg',
  highResImage: '/artworks/my-drawing.jpg',
